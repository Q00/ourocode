# RFC 0007: 데스크톱 터미널 UX parity 감사

- 상태: 감사 결과 (구현 RFC가 아님)
- 감사 시점: 2026-08-16
- 범위: 현재 Ourocode macOS AppKit/Metal 앱과 Rust broker, 공개 Ghostty/Warp/Kaku/Goose HEAD 비교
- 판정: `implemented` = 소스 경로와 계약 테스트가 존재함, `broken` = 일부 경로는 있으나 현재 런타임/계약 실패 또는 경쟁 터미널 대비 중요한 누락이 있음, `missing` = 사용자에게 노출되는 경로가 없음

## 기준 자료

비교 대상은 변동하는 `main`이므로 감사 당시 commit을 고정했다.

- [Ghostty `02436fd4`](https://github.com/ghostty-org/ghostty/tree/02436fd4eb0fca179f6d58717e9bc7a0ce106272): `src/input/Binding.zig`의 `new_tab`, `new_window`, split, pane navigation/resize, search, URL copy, font, clear, reload-config action과 [다중 shell integration](https://github.com/ghostty-org/ghostty/blob/02436fd4eb0fca179f6d58717e9bc7a0ce106272/src/shell-integration/README.md)을 기준으로 삼았다.
- [Warp `e72fd7aa`](https://github.com/warpdotdev/Warp/tree/e72fd7aacbbb2236d9b3be2aad7e7178fe94b4bc): 현재 client가 공개된 AGPL/MIT 혼합 저장소다([README licensing](https://github.com/warpdotdev/Warp/blob/e72fd7aacbbb2236d9b3be2aad7e7178fe94b4bc/README.md#licensing)). `app/src/pane_group/tree.rs`, `app/src/terminal/find/`, `app/src/terminal/links.rs`, `app/src/notification.rs`, `app/src/terminal/audible_bell/`, `app/src/terminal/local_tty/`를 행동 기준으로 삼았다.
- [Kaku `8b370e5f`](https://github.com/tw93/kaku/tree/8b370e5fadfd7721097928567f5b0180d71f3a7d)의 [keybindings](https://github.com/tw93/kaku/blob/8b370e5fadfd7721097928567f5b0180d71f3a7d/docs/keybindings.md)은 `Cmd-D`, `Cmd-Shift-D`, pane navigation/resize/zoom, tab navigator, `Cmd-K`, custom bindings까지 명시한다.
- [Goose `3810898a`](https://github.com/aaif-goose/goose/tree/3810898a7447ec3299be72e223d3570a7aabf0ab)은 터미널 엔진이 아니라 Rust agent/MCP + native desktop의 읽기 계층 기준이다. 따라서 Goose의 progressive message/tool 상태는 참고하되 PTY 기능의 증거로 세지 않았다.
- “Grok”은 터미널 앱/엔진 공개 저장소가 아니라 모델/제품 이름이므로 터미널 parity의 독립 기준으로 판정하지 않았다.

## 우선순위와 완료 기준

### P0 — 다음 acting QA 전 반드시 닫을 것

1. **실제 zsh contract:** stable Developer ID build의 Files and Folders consent를 먼저 고정하고 Powerlevel10k/instant-prompt와 함께 startup warning 0, OSC `A → B → C → D(status)` 순서, OSC 7 cwd, AX command rows > 0을 증명한다. OSC 133은 input authority가 아니며 누락되어도 PTY surface는 보이고 입력 lease는 유지된다.
2. **Terminal splits:** `Cmd-D`/`Cmd-Shift-D`, directional focus, divider drag preview/commit, pane close/zoom, exact broker terminal binding. 모든 visible leaf의 resize/reflow와 IME/copy/paste를 검증한다.
3. **Zoom/keyboard acting proof:** 새 빌드에서 `Cmd+`, `Cmd-`, `Cmd-0`가 first responder가 terminal/rail/palette여도 한 번만 적용되고 HUD·font atlas·PTY geometry가 함께 갱신된다. Shell 2 first-present 이후 Return은 한 번, Ctrl-C는 한 번만 전달되는 것을 재검증한다.
4. **Resource gate:** 1/4/8/32 tabs와 visible splits를 각각 cold/steady/close-to-baseline으로 측정한다. UI, broker, shell, agent, MCP descendants를 process coalition으로 합산하고 RSS와 `phys_footprint`/lifetime peak를 구분한다. hidden tab은 GPU surface/atlas/thread를 추가하지 않아야 한다.

### P1 — P0 이후 parity를 완성할 것

- Ghostty/Kaku식 configurable keymap, true clear-scrollback, new window/fullscreen, split shortcuts.
- user themes/palette/font/background와 live reload, per-workspace appearance.
- implicit URL detection/hover/copy URL 및 mixed (plain/VT/HTML) clipboard.
- durable window/focus/tab-order/split/scroll restore와 inactive-tab unread/desktop notifications.
- Bash/Fish/Nushell/Elvish shell integration, OSC notification variants, session-to-mobile read-only cursor transport.

## 결론

현재 구현은 “broker-backed single-surface terminal + tab/session rail”로서는 좋은 기반이며 zoom, tabs, search, copy/paste, path drop과 bounded memory 계약은 `implemented`다. 하지만 Warp/Kaku/Ghostty를 실제 터미널로 대체하려면 **사용자가 바로 누르는 splits/panes, 깨끗한 zsh shell integration, 정확히 한 번 전달되는 keyboard input**이 먼저다. 이 세 가지가 끝나기 전에는 테마나 Goose식 카드 polish를 parity 완료로 표시하지 않는다.
